# Wix (e-commerce) Cloud Application Assessment
Couture Customs by Gina, LLC. would like to onboard this cloud application to manage store inventory, collect and store customer data (name, address, card info, phone number), and take payments. 
- Risk assessment should be completed before onboarding to verify that Wix's security posture is up to par, identify Wix's risks, and determine whether the application aligns with organizational policies and compliance requirements.
# Objective
The objective of this SaaS cloud application assessment is to:

- Complete Business Impact Assessment to determine the criticality of the application and understand potential impacts if the application becomes unavailable, compromised, or misconfigured
- Identify security, privacy, and compliance risks
- Determine whether the vendor meets organizational security expectations
- Assess alignment with SOC 2/ISO 27001
- Evaluate IAM controls, MFA, and RBAC
- Verify how customer data is processed, stored, encrypted, and retained
- Review incident response processes and SLA guarantees
- Recommend remediation actions before deployment, if applicable

# Business Impact Assessment (BIA)
After completing a summary of questions on what data will be stored within Wix, it was determined that since Wix will contain customer PII, the impact level is automatically considered high. 
It will be considered HIGH because if the data is compromised, it can lead to multiple violations such as PCI and GDPR.
